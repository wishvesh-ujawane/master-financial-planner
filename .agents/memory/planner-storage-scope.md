---
name: Planner storage scope
description: The user's storage and backup boundary for the personal finance planner.
---

The user wants financial data stored locally and asked to prioritize core planner functionality before Google Drive backup or sign-in.

**Why:** the user explicitly deferred Drive while requesting the first core release.

**How to apply:** Keep planner records out of the server and use local browser storage with manual file backups. Do not add Google Drive or OAuth until the user reopens that scope.
